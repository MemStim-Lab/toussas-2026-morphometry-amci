Group-level statistical surface maps used for Supplementary Figure S2 panels C (SBM, full sample, n = 90) and D (SBM, matched subsample, n = 64).
Values are signed −log10 of the vertex-wise FWE-corrected p-value of the HO > aMCI cortical-thickness contrast (T statistic, TFCE toolbox output `T_log_pFWE_0001`), on the CAT12 32k mesh (left hemisphere followed by right). Each `.gii` reads its data from the `.dat` file of the same name; keep the two files together.
The corresponding SPM.mat files are not deposited because they contain participant-level covariates and file paths.
